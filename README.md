# Travel Landing

Travel Landing es una landing page estatica para una agencia de viajes con hero premium, destinos, galeria, testimonios, FAQ y formulario validado en JavaScript.

## Descripcion

El proyecto esta construido solo con HTML, CSS y JavaScript, con menu responsive, efectos reveal, parallax, slider de testimonios y validacion frontend.

## Tecnologias

- HTML5
- CSS3
- JavaScript
